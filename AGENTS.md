# Repository workflow

- Work directly on the `main` branch by default.
- Do not create or switch to a feature branch unless the user explicitly asks for one.
- Before making changes, confirm that the current branch is `main`. If it is not, switch to `main` when this can be done without discarding or overwriting existing work.
- Never discard uncommitted changes merely to switch branches; preserve them and report any conflict that prevents safe work on `main`.
